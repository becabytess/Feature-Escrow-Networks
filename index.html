The Recurrent Memory Bottleneck

SINGLE-STATE PATHOLOGY

For decades, sequential deep learning forced step-wise temporal dynamics and long-range information preservation to share the exact same state tensor. Every recurrent step risks overwriting past memories — state overwrite is not a bug. It is the architecture.

hT = f( hT−1, hT−2, … , x1, … , xT )
ONE STATE TENSOR · TWO ANTAGONISTIC JOBS · TO DECIDE AT STEP T, EVERYTHING MUST SURVIVE INSIDE h

JOB A — TEMPORAL DYNAMICS

Counting, local state transformation, noise filtering. Needs a fast, freely-updating state that can forget.

JOB B — LONG-RANGE PRESERVATION

Carry a fact from t = 1 to t = T intact. Needs a state that never changes. The two jobs fight over the same bits.

Dual-Pathway Architecture

ACTIVE TRANSFORMATION ⊕ PASSIVE ACCUMULATION

Biological & Theoretical Intuition

THREE COMPLEMENTARY LENSES
α

The Small-Intestine Doctrine

Nutrients don't ride the full length of the intestinal tube before absorption. The moment a particle is digested, it diffuses through the wall into the bloodstream — it never mixes with material still moving down the tract.

Standard RNNs treat memory like a closed pipe where everything must be dragged to the end. FEN treats features like nutrients: deposit when ready, and free the active loop for digestion.

DIGESTIVE FLUID → active loop hₜ  ·  NUTRIENTS → features φ(hₜ)  ·  BLOODSTREAM → escrow vault E
β

Speculative Write-Time Attention

Transformer attention is read-time backward selection: wait until step T, issue a query Q_T, and dot-product against every cached key — quadratic cost for the privilege of looking back.

FEN inverts the arrow. During training, φ(hₜ) learns to anticipate what the decision head will need, extracts it the instant it appears, and locks it into an O(1) vault. Attention's core benefit — selective, uncorrupted preservation — with no QKV, no caching, no O(T²).

READ-TIME — TRANSFORMER
WRITE-TIME — FEN
γ

Gradient Highways

In recurrent models, error from step T must crawl backward through T sequential matrix multiplications and forget gates — attenuating at every hop.

In FEN, the head connects directly to E = Σₜ φ(hₜ). Backprop delivers an un-bottlenecked shortcut from the loss to every historical state simultaneously. That immediate supervision is why FEN learns at epoch 1 what LSTMs need weeks of epochs to approach.

◆ DEPLICATE LAW — SUMMARY

Depletion is an optional pipe-hygiene switch, not a universal accuracy requirement. Turning it off — pure accumulation in roll_nodep and fen_copy — simplifies the model, yields superior early learning jumps, and achieves peak accuracy. It trims state norm; it does not buy accuracy.

PyTorch Implementation

MINIMAL · SELF-CONTAINED · roll_nodep

The universal default for sequential classification — Channel-Roll write without depletion. Note the doctrine in the code itself: amber lines carry the temporal state, cyan lines feed the escrow vault.

fen_roll_nodep.py PYTORCH 2.0+~40 LINES
TEMPORAL PATHWAY h ESCROW PATHWAY E 
import torchimport torch.nn as nn class FENRollNoDep(nn.Module):    """    Feature-Escrow Network with Channel-Roll Write (No Depletion).    Simple, fast, and SOTA among non-attention recurrent architectures.    """    def __init__(self, input_dim, hidden_dim, num_classes):        super().__init__()        self.hidden_dim = hidden_dim        self.x_proj   = nn.Linear(input_dim, hidden_dim)        self.core     = nn.Linear(hidden_dim, hidden_dim)        self.gate     = nn.Linear(hidden_dim, hidden_dim)        self.v_proj   = nn.Linear(hidden_dim, hidden_dim)        self.roll_gate = nn.Linear(hidden_dim, 1)        self.head     = nn.Linear(hidden_dim * 2, num_classes)     def forward(self, x):        B, T, _ = x.shape        h = x.new_zeros(B, self.hidden_dim)        E = x.new_zeros(B, self.hidden_dim)        x_p = self.x_proj(x)        for t in range(T):            z = h + x_p[:, t]            f = torch.tanh(self.core(z) + z)        # 1. recurrent state proposal            g = torch.sigmoid(self.gate(f))          # 2. extraction gate            D = g * f            v = self.v_proj(D)            h = f                                    # 3. temporal state — NO depletion            gamma = torch.sigmoid(self.roll_gate(f)) # 4. escrow channel-roll update            E = (1.0 - gamma) * E + gamma * torch.roll(E, shifts=1, dims=-1) + v        # 5. joint decision head over [h_T] and escrow vault [E]        return self.head(torch.cat([h, E], dim=-1))

Explicit Scope & Non-Claims

HONEST BOUNDARIES
✕

We do not claim universal SOTA over 2D Convolutional Networks or Transformers on vision / language tasks.

✕

We do not claim the Bag vault is superior for sequence ordering — Channel-Roll is the ordering specialist.

✕

We do not claim depletion is necessary for learning. It is optional pipe hygiene — sometimes it even costs peak accuracy.

◆ THE CORE FINDING

Decoupling temporal dynamics from feature accumulation via speculative write-time escrow resolves the single-state RNN bottleneck in O(T) time and O(1) memory — with attention-grade preservation and epoch-one learning speed.
