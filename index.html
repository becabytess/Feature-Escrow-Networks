Decoupling Temporal Dynamics from Information Preservation

A dual-pathway architecture that eliminates the single-state memory bottleneck of RNNs and LSTMs via speculative write-time feature accumulation.

Key Research Insight

Standard recurrent models force temporal computation and historical state preservation into a single hidden state trajectory $h_t = f(h_{t-1}, x_t)$, causing state overwriting and vanishing gradient pathologies. Feature-Escrow Networks (FEN) resolve this by introducing a secondary representation pathway $E = \sum_t \phi(h_t)$ that continuously extracts and accumulates temporal features during the forward pass. This achieves attention-like feature preservation in linear $O(T)$ time and $O(1)$ memory—outperforming LSTMs by massive margins (e.g. 88.7% peak & 69.1% Epoch-1 accuracy on sMNIST vs 11.0% for LSTMs).

The Recurrent Memory Bottleneck

For decades, sequential deep learning relied on single-state recurrent update equations. To make a decision at step $T$, classical models rely entirely on the final hidden state:

\[ h_T = f(h_{T-1}, h_{T-2}, \dots, x_1, \dots, x_T) \]

This design forces two fundamentally distinct computational roles—step-wise temporal dynamics (counting, local state transformation, noise filtering) and long-range information preservation—to share the exact same state tensor. Every recurrent step risks overwriting past memories. Gating mechanisms (such as LSTM forget/input gates) attempt to mitigate this, but memory remains bottlenecked inside the single active loop.

Transformers eliminated this bottleneck by caching all past states $h_1, \dots, h_T$ and using dynamic Query-Key-Value (QKV) attention matching. However, this read-time retrieval strategy incurs quadratic $O(T^2)$ compute and heavy KV-cache memory overhead.

Biological & Theoretical Intuition

Understanding Feature-Escrow Networks through dual complementary lenses: biological intestinal diffusion and speculative write-time attention.

1. The Biological Inspiration: Small Intestine Absorption ("Processed Features Diffuse")

In standard neural networks, intermediate features extracted at step $t$ or layer $l$ that are needed for a final decision at step $T$ are forced to be carried forward step-by-step through intermediate hidden units. This forces neurons to act as passive "pass-through conduits", burning state capacity and risking feature overwriting.

The Small Intestine Analogy: In the human digestive tract, nutrients do not wait to travel all the way through to the end of the intestinal tube before being absorbed. The moment a food particle is digested and ready, it diffuses immediately through the intestinal wall into the bloodstream. It does not stay in the active digestive fluid, nor does it mix with undigested material moving down the tube.

Standard RNNs treat memory like a closed pipe where everything must be dragged along until the end. Feature-Escrow Networks treat feature extraction like intestinal absorption: the moment a temporal feature is ready, the model deposits it into an auxiliary escrow vault ($E$). The active recurrent loop is freed from carrying that memory, allowing it to focus strictly on local temporal dynamics without fear of overwriting finished facts.

2. Mathematical Lens: Speculative Write-Time Attention

Standard Attention (Transformer) performs read-time backward selection: it waits until step $T$ to generate a Query $Q_T$, stores all past hidden states in memory, and computes dot products against past Keys $K_t$ to retrieve Values $V_t$. This incurs quadratic $O(T^2)$ time/space complexity.

In contrast, FEN performs speculative write-time accumulation. During end-to-end training via backpropagation, the feature extraction function $\phi(h_t)$ learns to anticipate what features downstream decision heads will require. As $h_t$ is generated during the forward pass, $\phi$ speculates future decision needs, extracts relevant features immediately, and locks them into an $O(1)$ auxiliary vault $E$.

This provides the core benefit of Attention—selective, uncorrupted feature preservation across long temporal horizons—in linear $O(T)$ time and $O(1)$ memory, without any QKV matrix operations, sequence caching, or $O(T^2)$ overhead.

3. Gradient Dynamics: Un-Bottlenecked Highways

The remarkable sample efficiency of FEN (Epoch-1 accuracy >69% vs 10% for LSTMs) is directly attributable to gradient routing.

In standard recurrent models, error gradients from decision step $T$ must backpropagate sequentially through $T$ steps of recurrent matrix multiplications and forget gates, causing severe gradient attenuation.

In FEN, the decision head connects directly to the escrow vault $E = \sum_t \phi(h_t)$. Backpropagation provides an un-bottlenecked gradient shortcut directly from the decision loss to every historical state transformation $\phi(h_t)$ simultaneously. This immediate, direct supervision signal drives rapid early convergence from the very first epoch.

Takeaway on Topology Matching

Delivery Operator Mechanics (`exp04`, `exp06`, `exp07`)

We systematically evaluated how features accumulated in $E$ should be delivered to downstream decision heads:

  • Decision-Time Read $\text{Head}([h_T, E])$: Default & optimal. Maintains clean $O(1)$ state bounds and peak sample efficiency.
  • Every-Step Reinjection ($E \to h_t$): Rejected. Pours accumulated state back into the active loop every step, causing severe norm bloat and degrading accuracy.
  • Multi-Pass Scans: A second full scan over $E$ does not beat single-pass decision-time read, confirming single-pass FEN is optimal.

4. Deplete Law & Real Waveforms

Dissecting state subtraction ($h \leftarrow h - D$) and real-world 1D sensor benchmarks.

The Deplete Law (`exp12`, `exp12b`)

In early FEN formulations, a depletion (subtraction) step $h_t \leftarrow h_t - D_t$ was evaluated to scrub extracted mass from active recurrent states. We conducted controlled ablations on Distracted Counting ($T=96$) and sMNIST ($T=400$):

Task / Topology No Deplete (Pure Accumulation) With Deplete Effect of Depletion
Distracted Counting Bag (`exp12`) 95.1% Peak (Pipe Norm: 5.36) 77.5% Peak (Pipe Norm: 1.84) Depletion Hurts Peak (-17.6%)
Distracted Counting Roll (`exp12`) 85.3% Peak (Pipe Norm: 5.59) 71.5% Peak (Pipe Norm: 2.38) Depletion Hurts Peak (-13.8%)
sMNIST Roll (`exp12b`) 69.1% Ep-1 / 88.7% Peak 64.0% Ep-1 / 88.1% Peak No Deplete is Pure & Superior

Deplete Law Summary

Depletion is an optional pipe-hygiene switch, NOT a universal accuracy requirement. Turning depletion off (pure accumulation in `roll_nodep` and `fen_copy`) simplifies the model, yields superior early learning jumps, and achieves peak accuracy.

Real 1D Waveform Benchmarks (`exp05`, `exp05b`)

We evaluated FEN on real-world ECG medical signals (MIT-BIH) and acoustic sensor classification (FordA):

  • MIT-BIH ECG Heartbeat Classification: Residual RNNs collapse to majority class. FEN Roll and FEN Bag achieve high classification accuracy (~92%+).
  • FordA Acoustic Noise Classification: Residual RNNs sit near chance. FEN Roll dominates performance, demonstrating strong feature extraction over raw sensor waveforms.

Explicit Scope & Non-Claims

  • We do not claim universal SOTA over 2D Convolutional Networks or Transformers on vision/language.
  • We do not claim Bag vault is superior for sequence ordering (Channel-Roll is for ordering).
  • We do not claim depletion is necessary for learning.
  • Our core finding is that decoupling temporal dynamics from feature accumulation via speculative write-time escrow resolves the single-state RNN bottleneck in $O(T)$ time and $O(1)$ memory.

PyTorch Implementation

Minimal, self-contained implementation of `roll_nodep`.

Below is the complete implementation of roll_nodep (Channel-roll write without depletion)—the universal default for sequential classification tasks:

fen_roll_nodep.py PyTorch 2.0+ 
import torch
import torch.nn as nn

class FENRollNoDep(nn.Module):
    """
    Feature-Escrow Network with Channel-Roll Write (No Depletion).
    Simple, fast, and SOTA among non-attention recurrent architectures.
    """
    def __init__(self, input_dim, hidden_dim, num_classes):
        super().__init__()
        self.hidden_dim = hidden_dim
        self.x_proj = nn.Linear(input_dim, hidden_dim)
        self.core = nn.Linear(hidden_dim, hidden_dim)
        self.gate = nn.Linear(hidden_dim, hidden_dim)
        self.v_proj = nn.Linear(hidden_dim, hidden_dim)
        self.roll_gate = nn.Linear(hidden_dim, 1)
        self.head = nn.Linear(hidden_dim * 2, num_classes)

    def forward(self, x):
        B, T, _ = x.shape
        h = x.new_zeros(B, self.hidden_dim)
        E = x.new_zeros(B, self.hidden_dim)
        x_p = self.x_proj(x)

        for t in range(T):
            z = h + x_p[:, t]
            f = torch.tanh(self.core(z) + z)        # 1. Recurrent state proposal
            g = torch.sigmoid(self.gate(f))          # 2. Extraction gate
            D = g * f
            v = self.v_proj(D)
            
            h = f                                   # 3. RNN temporal state (NO depletion)
            
            gamma = torch.sigmoid(self.roll_gate(f))# 4. Escrow channel-roll update
            E = (1.0 - gamma) * E + gamma * torch.roll(E, shifts=1, dims=-1) + v

        # 5. Joint Decision Head over final temporal state [h_T] and Escrow vault [E]
        return self.head(torch.cat([h, E], dim=-1))
